# Go Go ZabGU Tasks

Сборник учебных заданий по программированию на C для ЗабГУ.

## Содержание
Задания разложены по каталогам с номерами. Есть отдельные программы для работы с массивами, списками, файлами и матрицами.

## Сборка
В корне находится CMakeLists.txt. Откройте проект в IDE с поддержкой CMake либо выполните cmake -S . -B build и cmake --build build.

## Статус
Учебный репозиторий; у каждой задачи может быть собственная точка входа.
